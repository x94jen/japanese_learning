# 字卡切換、基礎工具與課程進度

## 字卡

字卡頂部有「上一張」「下一張」與「跳至字卡」。切換時回到卡片正面，停止舊卡音訊並保存位置；不會自動標記已學、熟悉或調整複習時間。自評仍需先翻卡，再選忘記／困難／記得／容易。

本次自評以字卡 ID 個別記錄。即使先跳到最後一張，也不會把前面的卡當作已完成；在最後一張自評後，若前面仍有未評項目，會回到第一張未評卡。全部自評後可「回看這組字卡」，回看不會重複排程。原本只有位置、沒有自評清單的舊字卡紀錄仍可讀取。

「暫停，保留進度」是離開字卡；前後看單字請使用「上一張」「下一張」。

## 基礎工具

入口：「考檢定 → 開啟基礎工具」。三個分頁：

- 五十音與發音：現代 46 個基本假名的平假名／片假名對照、25 個濁音／半濁音、33 個拗音組合、常見外來語音，以及促音、長音、撥音、小字、助詞讀音與易混片假名。可切換平／片假名、隱藏羅馬字、選字後用裝置語音播放。
- 動詞變化詳解：先看五段、一段、する、来る分類與五段音段表。17 個代表動詞可切換，逐一顯示 24 種常用形式的變化方式、意思、例句與完整中文。包括ます各時態、ない／なかった、て／た、なくて／ないで、可能、被動、使役、使役被動、意志、命令、禁止、ば／たら及否定條件、ず。
- 動詞統整表：橫向比較四種類別，附平假名讀音；可搜尋並跳到詳解。另列衍生動詞的否定／過去／禮貌組合、18 種常用接續句型與常見敬語對照。

讀音與詞性例外包括行く→行って、買う→買わない、帰る屬五段、ある→ない、する→せず、来る的き／こ／く。部分ある的衍生形式一般不用，以「—」標示。

這是優先涵蓋 N5～N3 的現代標準語整理，不宣稱包辦所有古文、方言、敬語詞彙與語用例外。來源標示為本站自編基礎整理，合成語音需裝置支援日文。

六節閱讀進度須按「完成這節閱讀」記錄。已讀不是熟悉，閱讀進度會使用現有本機保存與帳號同步機制。

## 課程進度

N3 與講義補充課的目錄、課程內頁，以及首頁課程卡均顯示進度條。首頁 N3 總進度會反映部分完成。

計算方式：完成的學習段落＋已作答題目＋最後明確標記完成。N3 有五個前置段落，講義補充有兩個。答錯仍表示已作答，但不表示掌握；熟悉程度繼續由間隔複習另外記錄。直接點到最後一段不會增加完成進度。原有已完成課程仍顯示100%，既有紀錄不刪除。

新字卡自評欄位、基礎工具閱讀事件及舊紀錄均納入備份／同步的格式驗證；Supabase 資料表不需要重建。更新後兩個裝置都應重新整理取得新版本。

## 動詞變化練習

「完整課程 → 開啟基礎工具 → 動詞變化練習」提供 427 題本站自編練習（非 JLPT 官方或歷屆試題）：403 題指定形式轉換、24 題句子填空，涵蓋 24 種形式及 17 個代表動詞。未將「ある」一般不使用的五種形式編成題目。

可按類別、形式、題型篩選，每次抽 5、10 或 20 題；不足時使用符合範圍的全部題目。動詞詳解的「練習這個變化」會帶入目前形式。句子提供中文語意，部分題目指定禮貌、時態或目標形式，以排除語境不足造成的多解。

共用原有答題系統：先回想再選擇，確認後顯示正確形式、讀音、規則、用途與易錯點。每題保存，收藏、錯題及間隔複習使用既有雲端事件；不需更動 Supabase SQL。複習中心單元篩選與「學習進度 → 基礎」包含動詞練習。題目單元 ID 為 200，與既有 N3／講義單元進度分開。
