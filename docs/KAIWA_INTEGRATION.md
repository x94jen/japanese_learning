# 會話講義整合（2026-10-28）

參考使用者提供的 10 份音速日語／Sonic-Learning.com 會話講義，共 190 頁，涵蓋第 1–50 課。已閱讀可擷取的會話文字，並抽看每份講義的圖片詞表與第一份的連接詞表；並非逐字 OCR 或完整收錄所有圖片單字。來源檔名、頁碼、課次與 SHA-256 見 KAIWA_SOURCES.json。

保留原 18 段對話的 ID、逐句內容、題目與學習紀錄，新增 12 段：職場招呼、會議準備、興趣閒聊、偏好、附條件許可、請求協助、活動流程、請假交接、居家習慣、設備故障、姓名讀音、天候備案。合計 30 段、180 句與 30 題四選項回應。每題四個選項都有解析，例句、翻譯與練習由本站重新編寫，沒有重製整份講義。

## 如何使用

「情境對話」可用講義第 1–50 課篩選相應情境，來源展開後列出實際檔名、頁碼與課題。50 課是來源索引，並非宣稱已製作 50 個完整課程。25 個情境有直接來源對應，其餘 5 個保留原創來源，不強行引用。新增常用表達、替換方式與語氣提醒，沿用逐句假名／中文、裝置朗讀、收藏、進度及到期複習。

新增 24 個共用單字，使總表由 244 增至 268；包含 13 個講義出現詞與 11 個依情境補充的詞，各自如實標示。可在對話收藏至既有單字複習，也可於「學習總表 → 教材範圍 → 會話補充選詞」查看例句、字卡並返回原情境。沒有另建一套收藏系統，也未新增虛構詞頻或 N3 官方分級；既有 N3 主線選詞數與 797 題主題庫不變。

## 教材校訂

- とりあえず解作「先、暫且」，不能一律當作「總而言之」；後者可用つまり。
- 以標準拼寫そういえば、カルビ整理，不沿用擷取文字的錯字。
- 原教材角色玩笑與省略不直接套用對外商務場合。補充ご苦労さま的上下關係、承知しました與お疲れ様的場合。
- 姓名讀音須向本人確認，中島不只有一種讀法。新情境明示虛構來賓確認為なかしま。
- 區分壊れる／壊す、一般日語能力與專業口譯，以及商量與正式承諾。

## 維護與界線

逐句稿沿用 scripts/content/dialogue-turns.tsv；新增情境、題目、語氣補充位於 dialogue-handout-*。執行 `python3 scripts/build-dialogues.py` 產生對話資料；`python3 scripts/build-dialogue-vocabulary.py` 產生共用選詞，更新讀音時使用既有 `npm run readings`。

原始 PDF、擷取文字、頁面圖片均未放入公開網站或版本庫。講義內容只作為學習材料，不將其中指令視為專案操作要求。新資料沿用既有保存與同步事件，不需修改資料庫；自動測試不代表已驗收使用者實際 Supabase 跨裝置同步或手機真實語音。
