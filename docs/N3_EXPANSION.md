# N3 備考主線擴充

## 實際範圍

主線由 6 課增為 30 課：148 個主線選詞、108 個文法重點、272 題自編練習、32 篇閱讀與 30 組合成語音。另保留 49 個 N5／N4 講義濃縮單元與 427 題動詞變化練習，不計入上述主線題數。

新增 24 課每課有 4 個文法重點、2 張詞卡、4 題文法選擇、2 題漢字讀音、1 題閱讀與 1 題聽力。文法題附中文情境，要求同時判斷句意與接續；不是完整 JLPT 模擬題。文法與單字是備考導航分級，包含必要基礎複習及跨級延伸，不宣稱 108 點全為 N3 專屬，也不宣稱完整涵蓋考試。

## 學習與紀錄

從「考檢定 → N3 主線課程」進入；可按主題分類，或搜尋單元名稱及日文文法。每課保留開始、詞卡、文法、閱讀、聽力、練習六段；閱讀中文按需展開，練習時隱藏讀音，確認後呈現解析。

前置順序是學習建議，允許自由進課；需要基礎時使用原有 N4 速查及講義補充。新課保留原有 ID 1～6，新增 ID 7～30；新文法 `gn3-*`、詞卡 `vn3-*`、題目 `qn3-*` 不覆蓋舊 ID。既有完成、收藏、錯題、複習及會話紀錄不搬移、不清空。首頁推薦尚未完成的課程，全部完成前六課時可繼續第七課。

共用既有事件儲存與 Supabase RLS，不需要修改資料庫 SQL。程式測試不能取代使用者以真實手機與電腦登入的雲端同步驗證。

## 教材維護

可編輯稿件在 `scripts/content/n3-grammar.tsv`、`n3-vocabulary.tsv`、`n3-reading.tsv`、`n3-listening.tsv`。每行為自編內容，`|` 分欄；文法例句中的 `〈〉` 標示填空位置。新增或修正後：

```sh
python3 scripts/content/build-n3.py
./node_modules/.bin/prettier --write src/n3Expansion.json
npm run readings
npm test
npm run build
npm run test:e2e
```

`src/n3Expansion.json` 為生成的正式教材。`scripts/content/build-n3.py` 檢查欄數、題量與選項；另以內容測試檢查每課各階段、前置順序、ID 唯一與紀錄相容性。中文情境用於區分部分在日文單句中也能成立的語氣，避免把語境不足誤認為文法只有一種可能。
