# 四選項逐項解析

所有 797 題皆提供原始選項順序的四份解析：370 題教材題目（322 題的干擾選項逐題撰寫；48 題擴充讀音題依實際對應的詞彙與讀音產生），以及 427 題動詞形式／句子練習（查詢同一份動詞變化表，辨識每個干擾選項的形式、讀音與用途）。正確選項沿用本題原有正解說明。

作答前不顯示逐項解析；確認後不論答對或答錯，四個選項皆顯示。解析編號跟隨題目已保存的選項亂序，標明正解、非本題答案與自己的選擇。錯題本同樣顯示全部選項，但以原始教材順序編號，透過選項文字及「你的選擇」標記辨識錯誤。

字卡內的句中辨義練習亦顯示四個選項的詞彙解說、讀音、搭配及與本詞的差別，排除相同中文意思的重複選項。新字卡錯誤紀錄保存四個詞彙 ID，匯出／匯入相容；舊紀錄沒有保存四項，保留既有單詞錯誤說明，不假造當時的干擾項。

解說區分「接續不成立」「形式不同」「意思或情境不同」「原文未提及」「順序、時間或角色不符」。不把可成立於其他語境的句子一概稱為不合文法。閱讀／聽力以原文資訊核對各項；排序題解說各片段的位置。

兩題干擾項校正：利用圖書館所需條件題以「につれて」替代可有合理解讀的「たびに」；程度比較題以「にとって」替代可能與原意接近的「より」。保留題目 ID、正解位置與作答進度，既有錯誤若涉及這兩個干擾項，會呈現目前版本的選項內容；未聲稱歷史選項全文已留存。

原始人工稿：scripts/content/question-option-notes.tsv。執行 `npx tsx scripts/build-option-explanations.ts` 重建 src/option-explanations.json。編譯檢查完整覆蓋與每題三份干擾說明；產物另保存選項文字，若選項內容改動而解析未更新，資料測試會失敗。

所有解析是本站整理，並非即時 AI 批改、官方解析或教師審訂。測試確認覆蓋率、解析與選項對應、動詞實際形式與顯示行為，不等同語言教師逐題審訂。

驗證：49 項資料／單元測試及 82 項手機／電腦瀏覽器案例通過，正式建置通過；涵蓋非第一項正解、題目亂序、答題前不洩漏、答對後仍解析四項、錯題回顧及字卡句中理解。
