# 依語境校正讀音

使用者回報 GL42 的「ドアが開きました。」在單字詞頭標示「あく」，例句卻由 Kuromoji 產生「ひらき」。此課按自他動詞對照的「あく／あける」統一，例句現在標示「あきました」。這不是宣稱「開く」所有語境都只能讀「あく」；「本を開く」「展示会を開く」等保留「ひらく」。

`src/pronunciation.ts` 保存有範圍的校正規則：只針對明確的門窗與營業時間語境，並按字元位置修正對應詞元；不做全域漢字取代。`scripts/build-readings.ts` 每次生成時套用規則，避免手改 JSON 後被下一次產生覆蓋。目前共有 11 個教材字串的對應標音被修正。

`AudioPlayer` 使用同一份校正規則，把目標詞轉成平假名後交給裝置日文語音，畫面仍保留原日文。這是校正傳入合成語音的文字，不是預錄真人音訊，也不代表所有多音字皆已人工審訂。

維護後執行 `npm run readings`、`npm test`、`npm run build`。測試包含原例句、ボタン／窓／図書館／店的相關句子、同句不同語境不誤改、生成資料的實際標音，以及桌面／手機上畫面的 ruby 和傳入語音引擎的文字。
