# 窗邊閱讀角與學習總表

## 窗景與版面

網站、登入頁與教材使用同一套暖色紙面、木質色調及閱讀書籤。首頁採原創生成的窗邊插畫；`src/assets/cafe-{morning,evening,night}.webp` 由此次生成的圖像轉成 WebP，原始生成圖保留於工作區，不發布第三方圖片。每張約 286～364 KB，頁面只載入當前時段的圖，不會為背景同時下載三張。

- 自動模式依**裝置當地時間**：06:00～15:59 晨光、16:00～18:59 夕暮、19:00～05:59 夜讀。
- 每 30 秒及回到頁面時檢查時段，不必重新整理。可選擇晨光、夕暮、夜讀，或恢復「隨時間」。點桌燈可在晨光／夜讀間切換。
- 頂端「窗景與閱讀燈」在所有學習頁面可用；提供「減少動態」。裝置的 `prefers-reduced-motion` 也會抑制裝飾動態。沒有自動音樂、雨聲或其他背景音訊。
- 外觀以 `hiyori-reading-room-v1` 存在此瀏覽器，與帳號及學習事件分開；跨裝置可各自選擇，不新增 Supabase 設定。
- 夜讀以深藍外框搭配低亮度暖色書頁，日文與解析不放在圖案上。窄手機將窗景與教材排成單欄；平板、桌面適用。
- 原有進度不改；首頁單元分母修正為實際單元數 30，原先硬寫的 6 不再顯示。

## 單字總表／文法總表

首頁「單字總表」「文法總表」，或導覽「學習總表」均可進入。課程頁的原共用詞目錄改為總表入口，避免一次列出所有單字造成長頁面。

共用既有教材：244 個單字、157 個文法重點（包含 N3 主線與 N5／N4 補充）。預設為 N3 主線 148 詞／108 個文法，可切換級數或全部教材。不是宣稱完整 N3 詞彙表。

- 搜尋日文、讀音或中文；選擇備考建議、日常常見度／日常溝通建議、原課程順序。
- 篩選到期、尚未熟悉或收藏；每頁 20 筆，手機採可讀的分列版面。
- 展開範例可看假名、完整中文、搭配、易混淆處；文法另有接續、常見錯誤、相似句型；支援裝置合成語音與返回完整單元。
- 3／5／10 分鐘快速複習分別取目前排序前 5／10／20 筆，時間為估計，少於上限時使用符合範圍的全部內容。可練相關題目。
- 單字沿用原字卡的辨義、讀音及聽音模式。文法字卡先回想，再翻面查看解說與例句；支援前後切換、跳題、收藏、自評與暫停接續。只有明確自評才寫入已學及間隔複習，不把翻卡或跳題當成學會。

文法會話事件 `grammarSession` 與 `lastStudyRoute` 通過既有備份驗證，沿用原 Supabase append-only 事件及 RLS，不需執行新的 SQL。首頁依最後一次學習類型接續，保留舊版會話的相容回退。真正手機／電腦雲端同步仍需同帳號實測。

## 排序的依據與限制

2026-10-22 實際讀取：

1. [Hermit Dave / FrequencyWords 日文 OpenSubtitles2018 詞頻](https://github.com/hermitdave/FrequencyWords/blob/master/content/2018/ja/ja_full.txt)。有 34,504 個詞元寫法條目；本站僅對完整寫法精確匹配，244 詞中 149 詞取得排名。未作詞形還原，未匹配**不表示少見**。語料為字幕，不能當作所有日常情境的排名，也不是日檢出題率。
2. [elzup/jlpt-word-list 的民間 N3 候選詞表](https://github.com/elzup/jlpt-word-list/blob/master/src/n3.csv)，溯源至 open-anki-jlpt-decks／Tanos，71 個現有詞卡以寫法及讀音匹配。僅保留收錄標記，不匯入英譯、例句或其他釋義；非官方分級。

「備考優先」先考慮 N3 主線候選詞與常見語料，再按課程順序穩定排序；「日常常見度」依可驗證的精確匹配排名，未匹配者保留課程順序。文法沒有可驗證的公開日檢出題率，因此備考／日常排序及兩條優先選讀路線都明示為**本站編排建議**。原 30 課的 ID、順序及前置提示保留，選讀路線不強迫鎖課。

未逐篇讀取的第三方文法網站不作排序資料來源。先前的時雨の町目錄仍是指定延伸閱讀，不宣稱已完成逐課核對。JLPT Sensei 目錄此次也因代理 HTTP 403 無法存取。

## 資料授權與重建

引用的詞頻排名、計數及其對應的衍生資料位於 `src/study-priority.json`，原作者 Hermit Dave／FrequencyWords，依 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 署名及相同方式分享；修改為只保留教材匹配資料與來源摘要。這項資料授權不把本站所有自編教材變成原資料的內容。來源網址、查閱日期、SHA-256、語料類型與匹配方式均在 JSON metadata 保留；沒有公開原字幕或原 CSV 釋義。

下載公開資料至工作區外，再執行：

```sh
python3 scripts/build-study-priority.py /tmp/ja_full.txt /tmp/n3.csv
./node_modules/.bin/prettier --write src/study-priority.json
npm test
npm run build
npm run test:e2e
```

`src/study-priority.ts` 保存人工文法優先級與選讀路線；它們是編排建議，不是頻率資料。
