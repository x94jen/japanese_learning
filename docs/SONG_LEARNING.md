# 日文歌學習

從側邊導覽或手機底部「日文歌」進入。第一版是可實際使用的私人教材工作區，不預載 Vaundy 完整歌詞或未驗證的字幕、翻譯。

## 加入歌曲

1. 輸入歌名、歌手與 HTTPS YouTube 影片網址，優先選歌手／唱片公司官方上傳。
2. 匯入有權使用的 SRT 或 VTT，或貼上有時間軸的字幕。最多 300 句、檔案 250 KB；拒絕時間重疊與無效區間。字幕需對應影片版本，並非自動從 YouTube 擷取。
3. 載入影片後，字幕位於下方，依時間切換；點句子跳轉，支援上一句、下一句、單句循環、影片支援的速度、日文／中文顯示及收藏篩選。
4. 編輯各句中文、語氣、省略、詩意與一般會話的差異。可校正單句起迄秒數。編輯時暫停影片以免句子自行切換。
5. 從共用單字／文法庫手動連結已核對的項目。單字預設僅建議原字串相符的詞，不是詞形或語境分析；文法以搜尋後手動確認。共用收藏可在原複習中心查閱。歌曲句子收藏在歌曲內透過「只看收藏」複習，尚未加入歌曲句子的 SRS。

空白翻譯或解析明確標示未提供；沒有固定假 AI 回覆，也不會把影片字幕當成官方翻譯。任意匯入歌詞的平假名不會自動產生；既有共用教材仍使用校訂讀音資料。這版不含錄音、發音評分、自動翻譯或 YouTube 字幕下載。

目前依使用者提供的清單，分三組提供 19 首 Vaundy 歌曲的 YouTube 搜尋入口，保留 Apple Music 來源連結，非已核對的官方影片連結，也不宣稱是演唱會歌單。後續需使用者指定歌曲、影片及提供字幕，再製作實際逐句教學。

## 播放與保存

- 按「載入影片」後才請求 YouTube IFrame API，使用 youtube-nocookie 嵌入；點擊前不載入 YouTube。仍屬第三方服務，可能有廣告、區域／嵌入限制。
- 影片服務失敗會顯示錯誤與原影片連結，手動逐句學習仍可操作。測試環境無法證明真實 Vaundy 影片可嵌入或時間對齊，需實機確認。
- 暫停、手動換句、播放進入下一句、返回總表會保存位置；重新開啟同曲接續原句，按載入影片後恢復時間，不自動播放。
- song、songProgress、songFavorite 事件通過既有備份與同步驗證，沿用使用者自己的 Supabase RLS。無資料庫遷移或額外服務訂閱，沒有變更原有 N3 ID 與作答紀錄。
- 只登入並成功連線雲端時可跨裝置同步；訪客只保存在本機。登入與郵件問題仍需完成原本的服務端設定，這個功能不代表已修復寄信。
- 每次修改教材沿用 append-only 事件保存完整歌曲資料。大量或頻繁修改字幕會增加備份、localStorage 與雲端空間；本版以少量歌曲使用為主。

## 驗證

41 項資料／單元測試及 68 項桌機／手機瀏覽器案例通過，正式建置通過。

以自編非歌詞測試句驗證 SRT／VTT 解析、時間邊界與間奏空白區、來源網址限制、事件合併／備份、桌機與手機字幕操作、筆記收藏、共用教材收藏與重開接續。播放器使用替身測試 seek／循環／速度，未宣稱已驗證真實串流或用戶 Supabase 同步。
