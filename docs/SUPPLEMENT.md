# N5／N4 講義補充教材

## 使用入口

登入後進入「考檢定」，切換「N5 基礎補充」或「N4 基礎補強」。可搜尋課次（例如 GL24）、句型與主題，也可依已完成／尚未完成篩選。N3 主線仍為預設入口，3／5／10 分鐘任務仍以 N3 新詞為主；到期複習可跨級數。

N3 單元內的快速補強可連到相關講義課程，例如て形、可能形、自他動詞與授受。補充單元也可直接返回相關 N3 單元，不必先完成全部 N5／N4。

## 來源與重新編寫

每課標示原檔名稱、原始頁數，參考第 1 頁的課綱。完整檔案清單與 SHA-256 在 [HANDOUT_SOURCES.json](HANDOUT_SOURCES.json)。原作者資訊以使用者持有的講義為準。

原 PDF、版面、原題、圖片與原附帶音訊不納入 GitHub／網站公開資源。本站解說、例句與練習另行編寫，並非歷屆試題，也未宣稱取得原作者全面轉載授權。此清單是課綱對照，不是原講義的全文入口。

針對原講義較簡化的說法，補上使用範圍與例外，例如：

- 自他動詞以句法與受詞角色判斷，並非單純「自己動／別人動」。
- ために／ように不能只憑自動詞、他動詞或助詞を、が判定。
- のです／んです著重背景說明，並非任意加強語氣。
- 推測文法不換算固定準確率，命令用法也不按性別作絕對區分。

音訊使用裝置日文合成語音，需自行確認裝置有日文語音，不是原講義錄音。

## 紀錄相容性

原本 v001～v100、q1～q80、g1～g12 與 N3 單元 ID 不變。新增詞卡從 v101、題目從 q81 開始。補充單元使用獨立編號，登入與 Supabase 資料表不需重新建立。驗證規則改成依實際教材 ID 判斷，讓新舊字卡與測驗的接續紀錄、備份和同步均可讀取。

「完成單元」需要走過前兩段並回答該課兩題，不等於已熟悉。翻卡不會直接標記學會，仍需自評並累積間隔複習。
